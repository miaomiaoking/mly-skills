# 错题收录使用说明（给用户看）

> 位置：`~/.workbuddy/skills/pdf-wrong-question-collector/USAGE.md`
> 一句话：给我一份 PDF，告诉我哪几题错了，剩下的（截题、找答案、进错题本、传 ima）我来。

## 一、怎么用

### 1. 把习题 PDF 发给我（或告诉我文件名）

支持两种方式：
- 直接把 PDF 文件拖进对话（最省事）；
- 只说文件名，比如「第9节课基础卷02」，我会在 `~/个人信息/宋泽辰/数学/`、`~/Downloads`、`~/Desktop` 里帮你找。

### 2. 说清楚哪几题错了

自然语言即可，不用记格式：

| 你说 | 我理解为 |
|---|---|
| 「第 5 题错了」 | 第 5 题 |
| 「5、9、12 错了」 | 三道题 |
| 「5 到 7 题错了」 | 第 5、6、7 题 |
| 「复习巩固第二题错了」 | 按板块 + 题号定位 |
| 「选择题第三题」 | 按题型 + 题号定位（我会先列出题号清单和你确认） |

题目编号在同一份卷子里会重复出现（填空题 1-12、应用题又从 1 开始），
**拿不准时我会先列出候选让你确认，不会瞎猜。**

### 3. 我会自动做完这些事

1. **截题**：从 PDF 里把整题（题干 + 选项 + 图形）按原版面高清截下来，绝不重绘、不改字；
2. **找答案**：自动在同目录找配对的答案卷（如《【答案】第9节课基础卷02.pdf》），截取该题"已填答案"的版本；
   - 找不到答案卷 → 答案页标「（答案待补）」，你可以口述答案让我补上；
3. **问你加到哪个错题本**（必问）：列出已有的错题本供你选，也可以新建；
4. **生成错题本 PDF**：版式固定——每题一张卡片（右上角黑字标注"原题出处：卷名 · 页码"），文末答案单独成页；
5. **上传 ima**：同步到「数学知识库 → 错题本」文件夹，同名自动覆盖，手机/平板上也能看。

### 4. 一句话示例

> 「@02+概率问题.pdf 复习巩固第 2 题错了，加到五下错题本」

完事后我会报告：收了哪几题、来自哪页、进了哪本、现共几题、ima 上传结果。

## 二、错题本说明

- **存放位置**：`~/个人信息/宋泽辰/数学/错题本/`
  - `<名称>.pdf` / `<名称>.html`：给人和打印看的成品；
  - `<名称>.json`：数据源（真身），删了 PDF 也能一键重建；
  - `figs/<名称>/`：每题截图的存档。
- **重复收录不会出错**：同一题（同来源同题号）再次加入时默认跳过并告诉你；
  确实要替换成新截图时说「覆盖」即可。
- **想改名/重排/删题**：直接说，数据在 json 里，随时可以重建。

## 三、常见问题

| 问题 | 回答 |
|---|---|
| 扫描版 PDF（图片型）能收吗 | 能截整页，但无法按题号自动定位，需要你告诉我页码，或我整页截图后你裁 |
| 答案页显示"（答案待补）" | 说明这份卷子没有配对的答案卷；把答案告诉我，我写进答案页；或之后拿到答案卷再补截图 |
| 答案是错的怎么办 | 答案截图直接来自官方答案卷，不是我做的；若确认原卷答案有误，告诉我正确答案，我以文字形式覆盖标注 |
| 图形被切掉一角 | 告诉我，我会调整裁剪范围重截，目检通过才交付 |
| 不想传到 ima | 说「不传 ima」，只生成本地 PDF |
| 错题本在哪本 | 随时问「列一下我的错题本」 |
